# Original QWitness branding

The logo and cover were newly drawn as SVG in scripts/capture-assets.ts, based on the original shield and graphite/ivory/mint palette in this project. PNGs are rendered with sharp. No stock imagery, reused project assets, generated screenshots, or external fonts are used.

- qwitness-logo.png: 512 × 512, square app logo.
- qwitness-cover.png: 1200 × 675, 16:9 cover.
- Matching SVG sources are included for editing.

The cover describes the product and receipt structure. It does not claim successful live execution, an audit, certification, or quantum-resistant Ethereum.
